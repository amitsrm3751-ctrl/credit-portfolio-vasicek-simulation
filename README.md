# Credit Risk Modelling & Portfolio Simulation (Vasicek + Bayesian Extension)

This project builds an end-to-end credit risk modelling pipeline, extending from loan-level estimation to portfolio-level loss simulation and Bayesian uncertainty modelling.

It combines classical credit risk modelling (PD, LGD, EAD) with Monte Carlo simulation, the Vasicek single-factor credit risk framework, and Bayesian inference for PD uncertainty.

---

## Project Overview

The project is structured in three layers:

### Layer 1 — Loan-Level Models
- Probability of Default (PD) — Logistic Regression with WoE features
- Loss Given Default (LGD) — Two-stage model (recovery flag + recovery rate)
- Exposure at Default (EAD) — CCF-based regression
- Expected Credit Loss: `ECL = PD × LGD × EAD`

### Layer 2 — Portfolio-Level Risk
- Correlated defaults via Vasicek single-factor framework
- Monte Carlo simulation of full loss distribution (10,000 scenarios)
- Risk metrics: Expected Loss, VaR (99.9%), CVaR, Economic Capital

### Layer 3 — Bayesian Extension
- PD modelled as a distribution (Beta-Binomial), not a point estimate
- Captures parameter uncertainty explicitly
- Enables data-driven stress scenarios (5th / mean / 95th percentile)

## Methodology

### 1. Data Preparation
- Filter resolved loan statuses (Charged Off, Fully Paid)
- Create binary default target variable
- Feature engineering: credit history length, employment length, months since issue
- Handle missing values with indicator variables
- Remove leakage variables

### 2. Variable Diagnostics
- Distribution and skewness analysis
- Event rate analysis by variable
- Constant variable removal

### 3. WoE Binning & IV Selection
- Weight of Evidence (WoE) transformation for scorecard modelling
- Monotonic binning for continuous variables
- Information Value (IV) for feature selection

### 4. PD Model — Logistic Regression
- WoE-binned dummy features as inputs
- Dummy variable trap handled by dropping reference categories
- Dual estimation: statsmodels (p-values) + sklearn (predictions)
- AUC = 0.79, KS = 0.44, Gini = 0.58

### 5. LGD, EAD & ECL
- **LGD:** Two-stage model — Stage 1: logistic (recovery flag), Stage 2: linear regression (recovery rate)
- **EAD:** Credit Conversion Factor (CCF) regression
- **ECL:** `PD × LGD × EAD` computed at loan level

### 6. Vasicek Asset Correlation (ρ)
Estimated from observed annual default rates using the moment estimator:

```
ρ = Var(Φ⁻¹(pₜ)) / (1 + Var(Φ⁻¹(pₜ)))
```

Estimated ρ ≈ 0.025 — consistent with Basel IRB retail portfolio ranges (0.01–0.05).

### 7. Monte Carlo Portfolio Simulation
Each borrower's asset return:

```
Aᵢ = √ρ · Z + √(1-ρ) · εᵢ
```

Conditional PD given economy Z:

```
PD(Z) = Φ( (Φ⁻¹(PD) - √ρ · Z) / √(1-ρ) )
```

Simulation steps per scenario:
1. Draw Z ~ N(0,1)
2. Compute conditional PD per loan
3. Simulate defaults
4. Sum portfolio loss

Outputs: EL, VaR (99.9%), CVaR, Economic Capital.

### 8. Bayesian PD Model (Beta-Binomial)
```
Prior:      PD ~ Beta(α, β)
Likelihood: D | PD ~ Binomial(n, PD)
Posterior:  PD | D ~ Beta(α + D, β + n - D)
```

Key insight: with large portfolios, the posterior collapses — uncertainty disappears. Bayesian stress testing is most meaningful at segment level (by grade or sub-grade).

### 9. Bayesian Vasicek Stress Testing
Three scenarios from the posterior:
- Optimistic → 5th percentile PD
- Baseline → posterior mean PD
- Stressed → 95th percentile PD

Each scenario propagated through the full Monte Carlo simulation.
